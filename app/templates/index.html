Core Architecture Features

Application Factory Pattern

🧩

Flask Blueprints

Modular routing organized inside app/main/ to keep application logic decoupled and clean.

🗄️

Flask-SQLAlchemy

Configured with SQLite in config.py and initialized in app/extensions.py without circular imports.

🔄

Flask-Migrate

Alembic-powered database schema migrations for smooth versioning of SQLite tables.
