Core Architecture Features

🏭

Application Factory Pattern

Configured in app/__init__.py using create_app(). Allows multiple instances and isolated unit testing.

🧩

Flask Blueprints

Modular routing organized into app/main/ and app/auth/ to keep application logic decoupled.

🗄️

Flask-SQLAlchemy

Configured with SQLite in config.py and initialized in app/extensions.py without circular imports.

🔄

Flask-Migrate

Alembic-powered database schema migrations for versioning and non-destructive SQLite alterations.

🔐

Flask-Login Session Auth

Full session management with login_user(), logout_user(), UserMixin, and @login_required.

🛡️

Secure Password Hashing

Passwords hashed with salted Werkzeug cryptographic hashes. Duplicate usernames and emails strictly prevented.
